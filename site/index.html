    Set up the repository

    Add the repository to your Termux installation, then install any package.

    1. 1
      Download the signing key 
      curl -LO https://apex-studio-dev.github.io/termux-packages/apexstudio-packages.asc
    2. 2
      Move the key into the apt keyring directory 
      mkdir -p $PREFIX/etc/apt/keyrings
mv apexstudio-packages.asc $PREFIX/etc/apt/keyrings/
    3. 3
      Add repository source(s) to $PREFIX/etc/apt/sources.list

    4. 4
      Update and install
